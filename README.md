# Abhishek Patel Portfolio

A responsive, static portfolio website for GitHub Pages.

## Preview locally

Open `index.html` in a browser, or run a local static server from this directory:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

1. Create a public repository named `YOUR-GITHUB-USERNAME.github.io`.
2. Upload the contents of this `portfolio` folder to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. GitHub Pages will publish the site at `https://YOUR-GITHUB-USERNAME.github.io`.

Alternatively, use this folder as the root of any GitHub repository and select that repository's `main` branch and `/ (root)` in Pages settings.

## Personalize

- Replace `assets/abhishek-patel.png` with another portrait if desired.
- Update the email address, profile copy, project descriptions, and dates in `index.html`.
- The site uses Google Fonts when a network connection is available and falls back to system fonts.
